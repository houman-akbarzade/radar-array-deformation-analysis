# Reproducible simulation figures

These figures were generated by `python/array_study.py` for the **synthetic public C-band model** described in the repository README. They are simulation outputs, not measurements from an antenna or a validated structural model. The public geometry and numerical settings are deliberately different from those of the underlying engineering project. The `figures/` directory contains a separately composed portfolio infographic and its generator.

## Baseline and frequency results

| File | Interpretation |
| --- | --- |
| `01_generator_validation.png` | Expected and empirical element displacement correlation from 10,000 generator draws at the upper band endpoint. This checks sampling statistics, not mechanical validity. |
| `02_geometry.png` | Nominal and one displaced set of active element positions in metres. |
| `03_displacement.png` | One realization: active-panel mean tangential displacement and distributions of tangential, radial, vertical, cylindrical-radius and element-azimuth changes. |
| `04_pattern.png` | Sum-pattern azimuth cut in dB relative to the nominal B peak for scenarios A–D. |
| `05_monopulse_curve.png` | Imaginary part of the difference-to-sum ratio where the sum response and calibration interval are valid. |
| `06_errors.png` | Distributions of beam-peak and monopulse errors across 500 realizations for C and D. |
| `07_error_relationship.png` | Paired beam-peak and monopulse errors in D; similar overall RMSE does not mean identical per-realization error. |
| `08_convergence.png` | Running conditional monopulse RMSE; invalid inversions are excluded and counted in CSV summaries. |
| `09_scenarios.png` | Beam-peak and monopulse RMSE for A (ideal single), B (nominal stack), C (deformed single), and D (deformed stack). |
| `10_receive_patterns_3d.png` | Illustrative receive-response surfaces calculated for the four scenarios; elevations of the stack are combined by pointwise maximum for display. |
| `11_frequency_displacement_statistics.png` | Mean displacement and per-element spread over five band frequencies. |
| `12_frequency_error_comparison.png` | Error RMSE by frequency and scenario. At the low endpoint, the chosen phase-centre bending gain is zero. |

The remaining top-level plots show selected parameter studies for mean tip displacement, tip standard deviation, and target elevation. `sensitivity/` contains the full parameter-sweep figures and their paired CSV summaries, including panel correlation, within-panel correlation, target azimuth/elevation, displacement scale and frequency. Sweeps reuse the seed at each setting to support paired comparison. Plot-specific axis labels and the associated CSVs give the values and units; do not generalize a single sweep point to a hardware tolerance.

At **5.8 GHz**, the `D_deformed_stack` baseline has a beam-peak shift RMSE of **0.085448°** and a monopulse error RMSE of **0.084084°** over 500 realizations (`scenario_summary.csv`). The infographic rounds these to 0.085° and 0.084°. Its one illustrated realization is not the Monte Carlo average. The actual project acceptance criterion is not published here, and these figures do not establish physical validation.

## Reproduction

From the repository root, install `python/requirements.txt` and run:

```bash
python python/array_study.py --mode baseline --trials 500 --validate-generator
python python/array_study.py --mode frequency --trials 500
python python/array_study.py --mode study --trials 500
```

The program writes into `output_python/`; copy those generated files into this directory only after checking that the configuration and run count match the committed summaries. The MATLAB model follows the same geometry and scenarios, but its random draws will differ and MATLAB execution has not been verified in this repository.
