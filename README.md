# Correlated Radar Array Deformation Analysis

**Status:** Initial repository scaffold; technical content pending review.

## Objective
Investigate how correlated mechanical displacement of antenna-array panels influences received phase, sum and difference beam patterns, and monopulse angle estimates.

## Repository structure
- `docs/`: mathematical model, simulation method, verification, results, limitations, and publication review.
- `report/`: LaTeX technical report and figure assets.
- `src/simulation_code/`: reviewed implementation (not yet uploaded).
- `examples/`: reproducible public-safe examples.
- `tests/`: verification tests.
- `results/figures/`: traceable results and figures.
