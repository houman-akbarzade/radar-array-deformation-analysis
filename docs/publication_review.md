# Pre-publication review checklist

**Status:** Pending.

- [ ] Confirm ownership and permission to publish each source file.
- [ ] Remove personal names, organization names, internal project names, identifiers, credentials, and metadata as appropriate.
- [ ] Review geometry, operating parameters, architecture, performance thresholds, and combinations of parameters for sensitivity.
- [ ] Review code, comments, commit history, figures, and LaTeX metadata.
- [ ] Verify replacement data and generalized examples cannot reveal restricted information.
- [ ] Obtain explicit approval before public release.
